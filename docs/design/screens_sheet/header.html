Nock screens sheet

Every screen and state of Nock (the client of main on 2026-10-22, with spec 043's room layout, approved on 2026-10-22), drawn in the validated design: the tokens, player colours, type, icons and components of specs/_design.md, and the cells of docs/design/cell-sheet.html. Each screen is drawn at phone width (360 px) and at computer width (1280 px, scaled down), with fr.json's strings.

Captions are in English, the interface in French. A grey label cites the section of _design.md or the spec a screen follows; a Decided P5 label names a decision the human took on 2026-10-22 from this sheet (now in _design.md); a dashed label marks what is still pending, listed in Decisions.

This page is generated by docs/design/screens_sheet/build.py. Every change of look updates _design.md and this sheet in the same change (_design.md §1, rule 3).

What is drawn

  • Catalogue with « Mes salons » and the history; its loading, empty and error states.
  • Entry: nickname, refusals, expired room, page not found.
  • The room: top bar, grid, clue bar, Salon (Discussion, Joueurs), Aide, Menu, host settings, timer, notes, reactions, connection band, catch-up, opening.
  • Help: check, reveal, vote, help off. Completion: bands, recap, shared page.
  • Account (sheet, page, deletion), operator page, keyboard, the two modes.

Rules kept

  • Only _design.md's tokens, sizes, radii, shadows and icons; no new colour.
  • The game is the core; every other page is one card or one column on the page grey.
  • A state is a line of text in place of its content: muted when waiting or empty, red when it failed, green when done.
  • Static page: no script; the width switch is CSS.
